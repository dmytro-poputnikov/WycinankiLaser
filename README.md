#WycinankiLaser
Narzędzie integracyjne dla jednoosobowej firmy wycinającej dekoracje z brystolu laserem (dekoracje szkolne i przedszkolne).

#Cel działania
Łączy się z Allegro REST API wyłącznie w celu zarządzania moim własnym kontem sprzedawcy:

- tworzenie i edycja ofert
- aktualizacja cen i stanów magazynowych
- obsługa zamówień i wysyłek

#Zakres dostępu
Jedno konto sprzedawcy — moje własne. Narzędzie nie świadczy usług innym sprzedawcom i nie przetwarza danych osób trzecich.
